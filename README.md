# Smart Packing List (เว็บจัดกระเป๋าตามสภาพอากาศอัจฉริยะ) ✈️🎒🌤️

เว็บแอปพลิเคชันสำหรับนักเดินทางที่ช่วยวิเคราะห์สภาพอากาศของเมืองปลายทางและสร้างรายการจัดกระเป๋า (Packing Checklist) ให้แบบอัตโนมัติ พร้อมระบบติดตามความคืบหน้าและบันทึกข้อมูลลงในเบราว์เซอร์

---

## 🌟 จุดเด่นและฟีเจอร์หลัก (Key Features)

### 1. การเชื่อมต่อ Third-Party Weather API
- **Open-Meteo Geocoding API**: ค้นหาพิกัด ละติจูด ลองจิจูด และประเทศของเมืองทั่วโลก รองรับทั้งภาษาไทยและอังกฤษ (เช่น "โตเกียว", "Tokyo", "London", "เชียงใหม่") พร้อมระบบ Auto-complete ค้นหาแบบเรียลไทม์
- **Open-Meteo Forecast API**: ดึงข้อมูลพยากรณ์อากาศล่วงหน้ารายวันได้สูงสุดถึง 16 วัน
  - คำนวณอุณหภูมิต่ำสุด-สูงสุด และค่าเฉลี่ย
  - วิเคราะห์โอกาสเกิดฝนตก (%) และปริมาณน้ำฝน (mm)
  - แปลงรหัสสภาพอากาศ WMO Weather Code แสดงผลเป็นไอคอนและภาษาไทยเข้าใจง่าย
  - **ข้อดี**: ใช้งานได้ทันที 100% ฟรี ไม่ต้องสมัคร API key หรือใส่บัตรเครดิต

### 2. Packing Recommendation Engine (ระบบแนะนำอัจฉริยะ)
- **ปรับตามสภาพอากาศจริง (Weather-Adaptive)**:
  - ❄️ **หนาวจัด / มีหิมะ (< 4°C)**: แนะนำเสื้อแจ็คเก็ตขนเป็ด/ดาวน์โค้ท, Heattech Ultra Warm, กางเกงบุขน, รองเท้าบูทกันลื่นลุยหิมะ, แผ่นแปะความร้อน (Kairo)
  - 🧥 **อากาศหนาวเย็น (4°C - 15°C)**: แนะนำเสื้อสเวตเตอร์, แจ็คเก็ตกันลม, เสื้อ Heattech, ผ้าพันคอ, หมวกไหมพรม, ถุงมือทัชสกรีน, ลิปมันและมอยส์เจอร์ไรเซอร์
  - ☀️ **อากาศร้อน (> 28°C)**: แนะนำเสื้อผ้าระบายอากาศ, กางเกงขาสั้น, แว่นกันแดด UV400, ครีมกันแดด SPF50+, หมวกปีกกว้าง, พัดลมพกพา, สเปรย์กันยุง
  - 🌧️ **ฝนตก (> 30% หรือมีฝนสะสม)**: แนะนำร่มพับพกพา, เสื้อกันฝน, ซองกันน้ำใส่มือถือ/พาสปอร์ต
- **ปรับตามจำนวนวันเดินทาง (Duration Scaling)**:
  - คำนวณจำนวนเสื้อยืดและกางเกงตามจำนวนวัน (พร้อมข้อความแนะนำให้ซักระหว่างทริปหากเดินทางเกิน 7 วัน)
  - เสื้อผ้าชิ้นสำคัญ เช่น ชุดชั้นใน ถุงเท้า คำนวณเผื่อสำรอง (+1 ชิ้น)
- **สิ่งของจำเป็นตายตัว (Universal Essentials)**:
  - เอกสารและการเงิน: พาสปอร์ต, บัตรประชาชน, บอร์ดดิ้งพาส, ใบจองโรงแรม, ประกันเดินทาง, Travel Card
  - อุปกรณ์อิเล็กทรอนิกส์: หัวแปลงปลั๊กสากล (Universal Adapter), พาวเวอร์แบงก์ (ระบุพกขึ้นเครื่อง), สายชาร์จ, eSIM
  - ยาสามัญและของใช้ส่วนตัว: ยาประจำตัว, พาราเซตามอล, ยาแก้เมารถ/แพ้, แปรงสีฟันขนาดพกพา

### 3. Dynamic Checklist & UX ที่ใช้งานง่าย
- **Interactive Checkbox**: ติ๊กเลือกของที่เก็บแล้ว พร้อมเอฟเฟกต์ขีดฆ่าและสีที่ปรับตามสถานะ
- **Progress Tracking**: แถบความคืบหน้าคำนวณ % การจัดกระเป๋าแบบ Real-time และเปลี่ยนสีเป็นสีเขียวเมื่อจัดครบ 100%
- **Filter Tabs**: กรองดูรายการตามสถานะ: "ทั้งหมด", "ยังไม่เก็บ", "เก็บแล้ว"
- **เพิ่มของเอง (Add Custom Item)**: เพิ่มสิ่งของเฉพาะตัว กำหนดจำนวน หน่วย หมวดหมู่ และเหตุผลได้
- **ลบ / แก้ไข**: ลบรายการที่ไม่ต้องการได้ทันที
- **ปุ่มลัดจัดการ**: "ติ๊กทั้งหมด" / "ยกเลิกทั้งหมด"

### 4. LocalStorage Persistence & Data Export
- **Auto-save**: บันทึกรายการสิ่งของและสถานะที่ติ๊กไว้ลง `localStorage` ทันทีที่มีการเปลี่ยนแปลง รีเฟรชหน้าจอข้อมูลไม่หาย
- **Saved Trips Bookmark**: บันทึกทริปที่ชอบเก็บไว้ในประวัติ (สูงสุด 20 ทริป) และกดสลับเปิดดูทริปเก่าได้ตลอดเวลา
- **Share & Export**:
  - คัดลอกข้อความสรุปรายการเช็กลิสต์ (Copy to Clipboard) เพื่อส่งต่อทาง LINE หรือ Note
  - สั่งพิมพ์ (Print / Save as PDF) ด้วยเลย์เอาต์พิเศษสำหรับการพิมพ์ใบเช็กลิสต์ลงกระดาษ
  - ดาวน์โหลดไฟล์สำรองข้อมูล JSON

## 🚀 วิธีการเปิดใช้งาน (How to Run)

คุณสามารถรันโปรเจกต์นี้ได้ง่ายๆ ด้วยคำสั่งต่อไปนี้:

### วิธีที่ 1: รันด้วย Python HTTP Server (แนะนำ)
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วพิมพ์:
```bash
python3 -m http.server 3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

### วิธีที่ 2: รันด้วย Node.js / npx serve
```bash
npx serve .
```

### วิธีที่ 3: เปิดไฟล์โดยตรง
สามารถดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ (Chrome, Safari, Edge, Firefox) ได้ทันที
